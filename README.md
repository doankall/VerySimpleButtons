# VerySimpleButtons

A simple button behavior for GDevelop.

Features:
- Detects clicks and hover events on sprites.
- Automatically animates sprites.
- Works only with Sprite objects.

Usage:
Add the "VerySimpleButton" behavior to your Sprite object. It includes a "Clicked" condition for detecting clicks. While this condition works with any Sprite object, the "VerySimpleButton" behavior is recommended for compatibility and animation support.
